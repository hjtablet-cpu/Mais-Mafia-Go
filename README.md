# Mais Mafia Go

Android-Overlay-Checkliste für den Querformat-Modus.

Funktionen:
- 13 feste Checklistenpunkte
- schmales halbtransparentes Overlay links
- Breite, Schriftgröße und Transparenz einstellbar
- Overlay verschiebbar
- Häkchen werden gespeichert
- Reset und Schließen direkt im Overlay
- keine Internetberechtigung

Die APK wird automatisch mit GitHub Actions gebaut.
